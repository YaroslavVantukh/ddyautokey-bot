DDY Autokey Telegram Bot

Функції:
- привітання нових учасників;
- +1 за відповіді зі словами: дякую, спасибі, дякс, спасибо, благодарю, thanks, thank you, thx, ty;
- +1 за реакції: 👍 🔥 ❤️ 🙏 👏 ✅;
- якщо позитивну реакцію прибрали, -1;
- самому собі репутацію додати не можна;
- /rep — показати репутацію;
- /top — топ-10 групи;
- службові повідомлення бота автоматично видаляються.

ВАЖЛИВО:
1. У BotFather відкрий /setprivacy → вибери свого бота → Disable.
2. Додай бота адміністратором у кожну групу, де він має працювати.
3. Для отримання message_reaction Telegram вимагає, щоб бот був адміністратором групи.
4. У Render додай Environment Variable:
   BOT_TOKEN = токен із BotFather
5. Токен НЕ додавай у GitHub.

Примітка:
На безкоштовному Render локальний файл SQLite може бути втрачений після нового deploy/restart.
Для постійного зберігання рейтингу пізніше краще підключити зовнішню БД.
